# تطبيق مركز الغفران

تطبيق Flutter للمحفّظ لإدارة طلاب حلقته وفتح ملفاتهم وإنجازاتهم وتسجيل حضورهم وتسميعهم وتصدير الكشوف، مع العمل دون إنترنت والمزامنة التلقائية مع Laravel.

## التجربة السريعة على هاتف Android

للإطلاق الرسمي دون Google Play استخدم [دليل الإطلاق](../docs/LAUNCH_GUIDE.md) و[دليل APK الموقّع والتحديث](../docs/MOBILE_DELIVERY.md). رابط التنزيل خاص بالمحفّظ ويظهر بعد تسجيل دخوله في لوحة النظام عند `/teacher/mobile-app`؛ لا توجد صفحة توزيع عامة. التعليمات التالية للشبكة المحلية ونسخة Debug فقط، وليست حسابات إنتاج.

الهاتف والحاسوب يجب أن يكونا على شبكة Wi-Fi نفسها. من جذر مشروع Laravel شغّل:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start-mobile-demo.ps1
```

ستظهر في النافذة وصلة الموقع ووصلة تنزيل APK. افتح الوصلة من الهاتف، ثبّت التطبيق، ثم استخدم:

```text
teacher1@gofran.com
123456789
```

يجب إبقاء نافذة الخادم مفتوحة أثناء التجربة. أول دخول يحتاج اتصالًا لتنزيل الحلقة والطلاب ومرجع القرآن؛ بعد ذلك يمكن فتح الملفات وتسجيل الحفظ وإضافة الطلاب وتعديلهم وأرشفتهم دون إنترنت.

إذا كان المنفذ `8000` مستخدمًا من خادم التطوير داخل IDE، يختار السكربت منفذًا متاحًا تلقائيًا ويعرض الرابط الصحيح؛ استخدم الرابط الذي يظهر في النافذة دائمًا.

إذا تغير عنوان IP للحاسوب، يكتشف السكربت ذلك ويعيد بناء APK متوافقًا تلقائيًا قبل تشغيل الخادم. ويمكن بناء الملف يدويًا عند الحاجة:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-mobile-test-apk.ps1
```

هذه نسخة Debug مخصصة للتجربة داخل الشبكة المحلية. نسخة النشر الفعلية تحتاج عنوان HTTPS ثابتًا وتوقيع Android خاصًا بالمركز.

## ملفات الطلاب والكشوف

- اضغط بطاقة الطالب لفتح ملفه المحفوظ على الجهاز: التقدم، الأجزاء، الإنجازات، وآخر السجلات.
- زر القلم يعدل البيانات غير الحساسة، وزر الأرشفة يخفي الطالب مع إبقاء تاريخه كاملًا.
- زر إضافة الطالب موجود أعلى قائمة طلاب الحلقة. ينشئ الخادم رقم الطالب تلقائيًا عند المزامنة.
- يمكن تسجيل تسميع لطالب أضيف Offline؛ ينتظر السجل اعتماد إنشاء الطالب ثم يرسل تلقائيًا بالمعرّف الرسمي.
- تبويب **ملفي** يعرض بيانات المحفظ وحلقاته، ومنه يطلب كشف Excel لكل حلقاته أو لحلقة محددة.
- إنشاء الكشف وتنزيله أول مرة يحتاجان الإنترنت. يمكن فتح آخر ملف نُزل سابقًا دون اتصال.
- أرقام الهوية ووثائق الطالب وولي الأمر لا تخزن في قاعدة الهاتف غير المشفرة؛ تستكمل من لوحة الويب الآمنة.

## اختبار العمل دون إنترنت والمزامنة

1. سجّل الدخول أول مرة والإنترنت متاح، وانتظر ظهور **حلقة النور** والطالبين.
2. افصل Wi-Fi وبيانات الهاتف، وافتح الحلقة ثم أحد الطلاب.
3. اختر الحضور، والسورة، وآية البداية والنهاية، والتقييم، ثم اضغط **حفظ السجل بأمان**.
4. ارجع إلى تبويب **المزامنة**؛ يجب أن يظهر السجل محفوظًا محليًا وبانتظار الإرسال.
5. أعد تشغيل Wi-Fi، ثم اضغط **مزامنة** أو اترك التطبيق مفتوحًا؛ عودة الاتصال تشغّل المزامنة تلقائيًا أيضًا.
6. عندما تظهر حالة **تم الاعتماد** يكون السجل قد وصل إلى MySQL رسميًا. تحقّق منه كذلك في شاشة التسجيل اليومي على الويب.

لا تحذف سجلًا مرفوضًا أو متعارضًا قبل قراءة السبب. التطبيق يطلب تأكيدًا صريحًا لأن حذف النسخة المحلية نهائي.

## التشغيل من Flutter

شغّل Laravel أولًا من جذر المشروع:

```bash
php artisan serve --host=0.0.0.0
```

ثم من مجلد `mobile`:

```bash
flutter pub get
dart run build_runner build
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1
```

- محاكي Android يصل إلى الجهاز المضيف عبر `10.0.2.2`.
- محاكي iOS يستخدم `http://127.0.0.1:8000/api/v1`.
- الهاتف الحقيقي يحتاج عنوان IP للجهاز داخل الشبكة، أو عنوان HTTPS للخادم.

## التحقق

```bash
flutter analyze
flutter test
flutter build apk --debug
```

الملف التجريبي الناتج:

`build/app/outputs/flutter-apk/app-debug.apk`

## قواعد المزامنة

- كل عملية تحمل UUID ثابتًا ينشأ على الهاتف.
- يحفظ السجل أولًا في SQLite ثم يرسل إلى الخادم.
- إعادة الإرسال لا تنشئ سجلًا مكررًا.
- التعارض لا يستبدل السجل الرسمي، بل يظهر في مركز المزامنة.
- رمز الدخول محفوظ في مخزن النظام الآمن، وليس في SQLite.
- لا يسمح التطبيق بتبديل الحساب أو تسجيل الخروج مع وجود سجلات غير محسومة، حمايةً من فقد البيانات أو إرسالها باسم حساب آخر.
- السجل المرفوض نهائيًا لا يعاد إرساله تلقائيًا؛ يظهر في مركز المزامنة للمراجعة والحذف ثم إعادة التسجيل الصحيح.
- مزامنة Android الدورية تعمل عند توفر الشبكة، ويعيد التطبيق المزامنة أيضًا عند فتحه أو عودة الاتصال.

راجع عقد الخادم في `../docs/mobile-sync-api.md`.

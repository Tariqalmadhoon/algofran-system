## جولة الاعتماد والتثبيت — 2026-08-20

- أعيد تنظيم شاشة التسجيل اليومي للمحفظ كتدفق واضح من الحلقة والطالب إلى الحضور وبنود التسميع والحفظ.
- أصبحت السورة مرتبطة مباشرة بـLivewire، وتُعاد قائمة الآيات بمفتاح DOM متغير عند تغير السورة، مع مزامنة سورة النهاية ومنع النطاق المعكوس.
- أصبح تقييم بند التسميع حيًا ويعرض الانتقال والخيار النشط فورًا بدل انتظار الحفظ.
- طُبق نمط إعادة بناء قوائم الآيات نفسه على نقطة بداية حفظ الطالب لمنع تكرار الخلل في ملف الطالب.
- فُحص مسار Livewire الفعلي على MySQL دون حفظ بيانات: اختيار آل عمران أعاد 200 آية، آية البداية 10 قيدت النهاية من 10، وانتقل التقييم إلى ممتاز.

## كشف الطالب السابق في التسجيل اليومي — 2026-09-08

- تعرض بطاقة كل طالب عدد سجلاته وآخر تاريخ، مع فصل إجراء «تسجيل اليوم» عن «الكشف السابق» حتى يبقى التاريخ متاحًا بعد إكمال سجل اليوم.
- يعرض الكشف السريع أحدث السجلات من الأحدث إلى الأقدم، مع الحضور والحلقة والمحفظ والتقييم العام ونطاقات الحفظ والمراجعة والأخطاء والتردد والتلقين والملاحظات.
- يدعم الكشف تصفية الكل والحفظ الجديد والمراجعة، وتحميل دفعات أقدم، والانتقال إلى ملف الطالب الكامل.
- نطاق الخادم يمنع فتح كشف طالب خارج الحلقة المسندة للمحفّظ حتى عند التلاعب بقيم Livewire.
- نجح فحص Livewire على MySQL الفعلية بحساب المحفّظ وبيانات حلقته دون إنشاء أو تعديل سجلات.

## المعمارية النهائية

- Laravel 12 / PHP 8.2 ضمن Modular Monolith.
- Blade + Livewire 4 + Tailwind CSS 4، واجهة عربية RTL بخط Tajawal محلي وسايدبار متجاوب قابل للطي.
- MySQL لبيانات المشروع وSQLite in-memory للاختبارات فقط.
- صلاحيات `spatie/laravel-permission` مع Policies وGate ونطاق رؤية مركزي للطلاب.
- Laravel Fortify للمصادقة الثنائية TOTP ورموز الاستعادة المشفرة، وLaravel Sanctum 4 لواجهة `/api/v1` برموز محدودة القدرة والمدة والجهاز.
- قرص `private` للوثائق والتقارير الحساسة، وقرص `public` لوسائط CMS المنشورة.
- طابور قاعدة البيانات للتصدير، Laravel Scheduler للتحليلات والتنظيف والمراقبة، وLaravel Reverb + Echo لإشعارات المستخدم الخاصة مع fallback مخزن.

## تحصينات PHASE 6

- قدرة `mobile:read` وصلاحيات وظيفية على موارد API، تحقق من المرشحات، وأخطاء JSON موحدة.
- انتهاء رموز API بعد 30 يومًا، تدوير رمز الجهاز، سحب الرموز عند تعطيل الحساب أو تغيير كلمة المرور، وتنظيف يومي.
- ترويسات أمان للمتصفح، وتحديد طلبات تسجيل الدخول والتواصل واستعادة كلمة المرور.
- معاملات ذرية للعمليات متعددة الجداول والملفات، وتنظيف الملفات عند الفشل.
- مهلة تصدير 900 ثانية مع `retry_after=960`، ومراقبة تراكم الطابور وتنظيف المهام الفاشلة.
- استعلام تجميعي واحد لاتجاهات لوحة المتابعة بدل 13 استعلامًا، وكاش قصير لإحصاءات الموقع العام.
- فهارس PHASE 6 مطبقة على MySQL في الدفعة 5.

## تشغيل PHASE 7

- `php artisan system:production-check` يرفض الإعدادات غير الآمنة، الترحيلات المعلقة، تعطل الخدمات، وحسابات العرض، ولا يكشف الأسرار.
- `GET /ready` يعرض حالة عامة فقط ويفحص قاعدة البيانات والكاش ومسارات الكتابة مع تحديد للطلبات ومنع التخزين المؤقت.
- `deploy/deploy.sh` و`deploy/deploy.ps1` ينفذان نشرًا قابلًا للتكرار. منذ تجهيز الإطلاق تبقى الصيانة مفعّلة عند الفشل حتى إكمال النشر أو الاستعادة المدروسة.
- `system:backup-manifest` ينشئ manifest بالحجم وSHA-256، و`system:backup-verify` يمنع الاستعادة عند فقد ملف أو تغييره.
- إنشاء تفريغ MySQL والأرشيفات الفعلية يبقى لدى خدمة النسخ المدارة أو أدوات النظام، ثم تمر الملفات عبر أوامر التحقق السابقة.

## الهوية والتسليم في PHASE 8

- 2FA متوفرة لكنها معطلة مؤقتًا بطلب المستخدم (`TWO_FACTOR_AUTH_ENABLED=false`). عند تفعيلها تصبح إلزامية للأدوار الإدارية والحساسة مع TOTP ورموز استعادة مشفرة.
- إعادة مصادقة لمدة 15 دقيقة قبل مركز الأمان، ومنه يمكن إدارة الجلسات والأجهزة وتدوير تطبيق المصادقة وإنهاء الجلسات الأخرى.
- دخول API للأجهزة ذات 2FA يستخدم challenge token عشوائيًا صالحًا لخمس دقائق وأحادي الاستخدام قبل إصدار Sanctum token.
- `X-API-Version: 1` و`GET /api/v1/meta` يثبتان عقد العميل. اعتمد لاحقًا تطبيق Flutter للمحفّظ مع SQLite ومزامنة يومية آمنة دون اتصال بدل قرار PWA-first السابق.
- إشعارات اكتمال التصدير والتنبيهات الحرجة تبث على قناة المستخدم الخاصة عبر Reverb، وتبقى database notifications وpolling كل 30 ثانية fallback دائمًا.

## تطبيق Flutter والتسجيل دون اتصال — 2026-08-31

- تطبيق Android عربي RTL للمحفّظ يعرض حلقته وطلابه ويسجل الحضور والتسميع والتقييم والملاحظات.
- أول دخول متصل ينزل الحلقة والطلاب ومرجع القرآن، ثم يحفظ العمل الميداني محليًا في SQLite عند انقطاع الإنترنت.
- عودة الشبكة وفتح التطبيق وWorkManager وزر المزامنة اليدوي كلها تشغّل إرسال السجلات المعلقة.
- عمليات المزامنة idempotent، مربوطة بالمستخدم والجهاز، وتفصل بين المعتمد والمتعارض والمرفوض والفشل المؤقت.
- يمنع التطبيق فقد البيانات عند تسجيل الخروج أو تبديل الحساب مع وجود outbox غير محسوم.
- نسخة APK التجريبية متاحة من الموقع العام، مع سكربت آلي للبناء على عنوان الشبكة وسكربت لتشغيل خادم التجربة.

## تطبيق Flutter: ملفات الطلاب وإدارتهم — 2026-09-03

- رُقّي عقد المزامنة إلى `schema_version: 3` مع ملف المحفّظ، ملفات طلاب حلقاته، التقدم، الإنجازات وآخر السجلات؛ وتبقى النسخة المحلية متاحة دون إنترنت.
- يستطيع المحفّظ إضافة طالب إلى حلقته وتعديل بياناته غير الحساسة وأرشفته وظيفيًا من التطبيق، مع رقم طالب متسلسل يولده الخادم وعدم حذف السجلات التاريخية.
- إنشاء الطالب والتسميع التابع له يعملان دون اتصال باستخدام `client_uuid`؛ تُزامن عملية إنشاء الطالب أولًا ثم يُربط المعرّف الرسمي بالسجل اليومي داخل معاملة محلية.
- التعديل يستخدم `base_updated_at` لمنع الكتابة فوق تحديث أحدث، وتفصل الواجهة بين التعارض والرفض والفشل المؤقت وإعادة المحاولة.
- بيانات الهوية ووثائق الطالب وولي الأمر لا تُخزن في SQLite على الهاتف؛ تستكمل من لوحة الويب الآمنة.
- يعرض ملف المحفّظ حلقاته وإحصاءاته، ويتيح إنشاء وتنزيل كشوف Excel المحصورة بحلقاته. يحتاج الإنشاء والتنزيل الأول إلى الإنترنت، ثم يمكن فتح الملف المنزّل دون اتصال.
- الإصدار التجريبي الحالي `1.2.0+3`، واسم الملف `gofran-mobile-1.2.0-test.apk`.

## الغياب والتحليل الشهري — 2026-09-09

- أصبحت حالتا `absent` و`excused` غيابًا أكاديميًا لا تسمحان بتسجيل بنود تسميع أو تقييم عام، مع تطبيق القاعدة في Livewire والإجراء المركزي ومزامنة الجوال والواجهة المحلية للتطبيق.
- نسبة الالتزام تحسب الحاضر والمتأخر في البسط، وتشمل الحاضر والمتأخر والغائب والغياب بعذر في المقام؛ لذلك لا يُعامل الغياب بعذر كحضور.
- أضيف ترتيب للفترة في لوحة المتابعة يدمج نطاقات الحفظ الجديد المتداخلة، ويعرض الآيات الفريدة وما يعادلها تقريبًا من الأجزاء، وترتيبي الحفظ والالتزام والحضور والغياب لكل طالب.
- ينشأ تنبيه شهري عند أول غياب دون عذر، وتنبيه عند اليوم الرابع من الغياب بعذر، ويصل مرة واحدة إلى مدير المركز والمحفظين ذوي الإسناد الفعّال مع إزالة تكرار المستلم.
- بصمة تنبيه الغياب مرتبطة بالشهر، فلا تمنع متابعة شهر جديد، ولا يعاد فتح تنبيه محلول دون زيادة فعلية في عدد أيام الغياب.

## تجهيز الإطلاق وتحسين الحركة — 2026-09-10

- النطاق المعتمد `https://algofran-center.tech` وAPI `/api/v1`؛ تنزيل Android خاص بالمحفّظين من `/teacher/mobile-app` بعد تسجيل الدخول، ولا توجد صفحة تنزيل عامة. لم يُنفّذ نشر خارجي أو تعديل `.env` المحلي أو حذف بيانات MySQL.
- توحيد حركة الظهور والتنقل والتنبيهات للواجهة العامة والضيف وLivewire؛ تأخير قصير محدود، احترام تقليل الحركة والطباعة، وعدم تحويل حاويات النوافذ العائمة. إصلاح نصوص sidebar المطوي على الهاتف وإغلاق القائمة العامة خارجها. لا تعتمد الواجهات التنقل الجزئي غير المختبر.
- قناة Android هي APK موقّعة ذات تحديث داخل التطبيق، دون Google Play. لا ينشر الموقع Debug، ولا حزمة ناقصة أو غير مطابقة للنطاق والنسخة والحجم والبصمة وmanifest.
- إنشاء مفتاح توقيع دائم خارج Git مع صلاحيات محلية مقيدة، وسكربت يرفض استبداله. يلزم المستخدم نسخه احتياطيًا مشفرًا خارج الحاسوب قبل التوزيع؛ لا يوضع المفتاح في Artifact أو الاستضافة.
- فحص تحديث عند فتح التطبيق/استئنافه وبعد المزامنة، وزر يدوي؛ فحص الحجم والبصمة والتوقيع والهوية، منع redirects والنطاقات الأخرى، ومنع التثبيت بوجود outbox غير محسوم وإتاحة إعادة فتح المثبت بعد الإلغاء.
- Workflow ويب لمساري shared/VPS مع قفل ونشر SHA المختبر، أصول مبنية في CI، preflight خاص بالاستضافة المشتركة وجذر الويب الفعلي، وCron للطابور والمجدول. لا يوجد حذف بيانات أو rollback تلقائي.
- Workflow يدوي مستقل لبناء Android بمفتاح دائم محفوظ في GitHub Secrets مع pin لبصمة الشهادة. يخرج APK وSHA-256 وmanifest فقط، ولا يرفعها إلى الاستضافة تلقائيًا.
- اختبار Bootstrap الإنتاج يؤكد مرجع القرآن والصلاحيات وحساب المدير فقط، دون بيانات التجربة، مع عدم تغيير كلمة مرور مدير موجود عند إعادة التهيئة.
- فحوص Laravel النهائية بعد كل التعديلات: **102 اختبار و1211 تحققًا ناجحًا**. يشمل ذلك ربط تنزيل API بالنطاق الموثوق وتطبيع إعداد البث `null` للاستضافة المشتركة.
- Flutter: **23 اختبارًا ناجحًا**؛ `flutter analyze` وبناء Release والتحقق من التوقيع وVite build وPint وصياغة Bash/PowerShell/YAML/JavaScript ناجحة. `composer audit` و`npm audit --omit=dev` دون ثغرات معروفة وقت الفحص.

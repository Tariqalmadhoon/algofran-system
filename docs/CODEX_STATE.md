`PHASE 8 — Strong Identity, Real-time and Mobile Delivery`

الحالة: مكتملة بتاريخ 2026-08-19. اكتملت الهوية القوية والتحديثات الفورية وعقد تسليم الجوال المحدد في الخطة. أُنجزت جولة اعتماد وتثبيت إضافية بتاريخ 2026-08-20 بطلب المستخدم، ولا يبدأ تطوير إضافي جديد دون طلب صريح.

## جولة الاعتماد والتثبيت — 2026-08-20

- أعيد تنظيم شاشة التسجيل اليومي للمحفظ كتدفق واضح من الحلقة والطالب إلى الحضور وبنود التسميع والحفظ.
- أصبحت السورة مرتبطة مباشرة بـLivewire، وتُعاد قائمة الآيات بمفتاح DOM متغير عند تغير السورة، مع مزامنة سورة النهاية ومنع النطاق المعكوس.
- أصبح تقييم بند التسميع حيًا ويعرض الانتقال والخيار النشط فورًا بدل انتظار الحفظ.
- طُبق نمط إعادة بناء قوائم الآيات نفسه على نقطة بداية حفظ الطالب لمنع تكرار الخلل في ملف الطالب.
- فُحص مسار Livewire الفعلي على MySQL دون حفظ بيانات: اختيار آل عمران أعاد 200 آية، آية البداية 10 قيدت النهاية من 10، وانتقل التقييم إلى ممتاز.

## المعمارية النهائية

- Laravel 12 / PHP 8.2 ضمن Modular Monolith.
- Blade + Livewire 4 + Tailwind CSS 4، واجهة عربية RTL بخط Tajawal محلي وسايدبار متجاوب قابل للطي.
- MySQL لبيانات المشروع وSQLite in-memory للاختبارات فقط.
- صلاحيات `spatie/laravel-permission` مع Policies وGate ونطاق رؤية مركزي للطلاب.
- Laravel Fortify للمصادقة الثنائية TOTP ورموز الاستعادة المشفرة، وLaravel Sanctum 4 لواجهة `/api/v1` برموز محدودة القدرة والمدة والجهاز.
- قرص `private` للوثائق والتقارير الحساسة، وقرص `public` لوسائط CMS المنشورة.
- طابور قاعدة البيانات للتصدير، Laravel Scheduler للتحليلات والتنظيف والمراقبة، وLaravel Reverb + Echo لإشعارات المستخدم الخاصة مع fallback مخزن.

## تحصينات PHASE 6

- قدرة `mobile:read` وصلاحيات وظيفية على موارد API، تحقق من المرشحات، وأخطاء JSON موحدة.
- انتهاء رموز API بعد 30 يومًا، تدوير رمز الجهاز، سحب الرموز عند تعطيل الحساب أو تغيير كلمة المرور، وتنظيف يومي.
- ترويسات أمان للمتصفح، وتحديد طلبات تسجيل الدخول والتواصل واستعادة كلمة المرور.
- معاملات ذرية للعمليات متعددة الجداول والملفات، وتنظيف الملفات عند الفشل.
- مهلة تصدير 900 ثانية مع `retry_after=960`، ومراقبة تراكم الطابور وتنظيف المهام الفاشلة.
- استعلام تجميعي واحد لاتجاهات لوحة المتابعة بدل 13 استعلامًا، وكاش قصير لإحصاءات الموقع العام.
- فهارس PHASE 6 مطبقة على MySQL في الدفعة 5.

## تشغيل PHASE 7

- `php artisan system:production-check` يرفض الإعدادات غير الآمنة، الترحيلات المعلقة، تعطل الخدمات، وحسابات العرض، ولا يكشف الأسرار.
- `GET /ready` يعرض حالة عامة فقط ويفحص قاعدة البيانات والكاش ومسارات الكتابة مع تحديد للطلبات ومنع التخزين المؤقت.
- `deploy/deploy.sh` و`deploy/deploy.ps1` ينفذان نشرًا قابلًا للتكرار ويضمنان إلغاء وضع الصيانة عند الخطأ.
- `system:backup-manifest` ينشئ manifest بالحجم وSHA-256، و`system:backup-verify` يمنع الاستعادة عند فقد ملف أو تغييره.
- إنشاء تفريغ MySQL والأرشيفات الفعلية يبقى لدى خدمة النسخ المدارة أو أدوات النظام، ثم تمر الملفات عبر أوامر التحقق السابقة.

## الهوية والتسليم في PHASE 8

- 2FA إلزامية للأدوار الإدارية والحساسة، واختيارية لبقية الحسابات، مع TOTP ورموز استعادة أحادية الاستخدام مشفرة في قاعدة البيانات.
- إعادة مصادقة لمدة 15 دقيقة قبل مركز الأمان، ومنه يمكن إدارة الجلسات والأجهزة وتدوير تطبيق المصادقة وإنهاء الجلسات الأخرى.
- دخول API للأجهزة ذات 2FA يستخدم challenge token عشوائيًا صالحًا لخمس دقائق وأحادي الاستخدام قبل إصدار Sanctum token.
- `X-API-Version: 1` و`GET /api/v1/meta` يثبتان عقد العميل، مع قرار PWA-first موثق ومنع offline cache للبيانات الخاصة.
- إشعارات اكتمال التصدير والتنبيهات الحرجة تبث على قناة المستخدم الخاصة عبر Reverb، وتبقى database notifications وpolling كل 30 ثانية fallback دائمًا.

## آخر تحقق

- `php artisan test`: 44 اختبارًا و360 تحققًا ناجحًا.
- `vendor/bin/pint --test`: ناجح.
- `npm run build`: ناجح مع أصول Tajawal المحلية.
- `composer audit` و`npm audit --omit=dev --registry=https://registry.npmjs.org`: لا توجد ثغرات معروفة وقت الفحص.
- `php artisan migrate:status`: ترحيل هوية PHASE 8 مطبق على MySQL في الدفعة 6.
- `php artisan schedule:list`: خمس مهام مجدولة ظاهرة دون تعارض.
- `php artisan system:production-check`: نجح باختبار إعداد إنتاج مقوّى، ورفض إعداد التطوير المحلي كما هو متوقع بسبب debug وHTTP والبريد التجريبي وغياب مفاتيح Reverb وعدم إعداد 2FA لحسابات العرض.
- `/up` و`/ready`: استجابة HTTP 200 فعلية محليًا، مع نتيجة عامة فقط ومنع تخزين استجابة readiness.
- `/api/v1/meta`: استجابة HTTP 200 فعلية مع `X-API-Version: 1`، وصفحة أمان الحساب ظهرت فعليًا لحساب الإدارة المحلي.
- سكربتا النشر: فحص صياغة PowerShell وBash ناجح.
- فحوص HTTP للموقع العام وAPI meta و`/up` و`/ready` ولوحة المحفظ والطلاب والتقويم والإشعارات: استجابات 200 فعلية ناجحة.
- فحص Livewire الفعلي لشاشة التسجيل اليومي: تحديث السورة والآيات وتقييد النهاية وانتقال التقييم ناجح على قاعدة MySQL.
- تدقيق بنية التجاوب ونقاط الكسر وحاويات الجداول: ناجح. الفحص البصري اليدوي على المقاسات الأربعة باقٍ ضمن قائمة ما قبل فتح الإنتاج لعدم توفر جلسة المتصفح المدمج في آخر جولة.
